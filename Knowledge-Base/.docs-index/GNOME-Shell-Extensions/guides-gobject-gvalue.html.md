GValue | GNOME JavaScript Skip to content Menu Return to top On this page GValue ​ GObject.Value is a generic value container, usually only used to implement GObject Properties in projects written with the C programming language. By storing the value type alongside the value, it allows for dynamic type features usually not available to C programmers. In JavaScript, this behavior is part of the language (i.e. typeof ) and GJS will usually convert them automatically, but there are some situations that require using GObject.Value directly.
